## 1. Metrics Definition

For each sorter, the following metrics are computed from the `unit_counts.csv` files (only rows with `dataset == 'edsr'`):

- **Recall**: `num_well_detected / num_gt`
- **Precision**: `(num_sorter - num_false_positive - num_redundant - num_overmerged) / num_sorter`
- **F1**: `2 * recall * precision / (recall + precision)`

Final tables report **mean ± std** across all sorters for each (Factor, Method) combination.

```python

precision = (num_sorter - num_fp - num_redundant - num_overmerged) / num_sorter      # (2)

```

Average: `mean ± std` across all sorters per (Factor, Method) pair.
